# Отчет по лабораторной работе №8: Цветокоррекция изображений

## Описание программы

### `task08` — система цветокоррекции изображений

* Входные данные:
  - Путь к изображению из `test_images`

* Реализованные алгоритмы:
  1. **Метод "Серый мир" (Gray World)**:
     - Расчет средних значений по каналам
     - Нормализация цветовых компонент
     - Автоматическая балансировка цветов

  2. **CLAHE в пространстве Lab**:
     - Конверсия BGR→Lab
     - Адаптивное выравнивание гистограммы для L-канала
     - Обратная конверсия Lab→BGR

  3. **Метрики качества**:
     - MSE (Mean Squared Error)
     - PSNR (Peak Signal-to-Noise Ratio)
     - SSIM (Structural Similarity)

* Выходные данные:
  - Корректированные изображения в `result_images/`
  - Гистограммы в `histograms/`
  - Текстовые отчеты с метриками в `color_correction_quality/`

## Сравнительные метрики

| Метод          | Средний MSE | Средний PSNR      | Средний SSIM |
| -------------- | ----------- | ----------------- | ------------ |
| Gray World     | 525.66      | 20.92             | 0.813        |
| CLAHE          | 613.75      | 20.25             | 0.624        |

- **MSE**: Среднеквадратичная ошибка (чем меньше, тем лучше)
- **PSNR**: Пиковое отношение сигнал/шум (чем больше, тем лучше)
- **SSIM**: Индекс структурного сходства (1.0 - идеальное совпадение)
