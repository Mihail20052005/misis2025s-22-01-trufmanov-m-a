# Отчет по лабораторной работе №7: Детектирование границ объектов

## Описание программ

### `task07-01` — детектор границ объектов

- Принимает на вход тестовое изображение из lab04
- Для каждого эллипса на изображении:
  - Применяет Гауссово размытие
  - Выполняет бинаризацию 
  - Находит контуры объектов
  - Аппроксимирует контуры 
  - Фильтрует дубликаты 
- Сохраняет:
  - Изображение с выделенными границами 
  - JSON-файл с параметрами обнаруженных эллипсов (координаты, размеры, угол, контур)

### `task07-02` — оценка качества детектирования

- Принимает два списка файлов:
  - Файлы с эталонными данными (GT из lab04)
  - Файлы с обнаруженными границами
- Для каждого изображения вычисляет:
  - True Positives (правильно обнаруженные эллипсы)
  - False Positives (ложные срабатывания)
  - False Negatives (пропущенные эллипсы)
  - Precision и Recall
- Метрика сравнения основана на:
  - Нормализованном расстоянии между центрами
  - Сходстве размеров (ширина/высота)
  - Разнице углов поворота
- Сохраняет сводный отчет в JSON

## Отчет: `report.json`

| Файл          | TP | FP | FN | Precision | Recall |
|--------------|----|----|----|-----------|--------|
| collage_1.png | 25 | 0  | 0  | 1.0       | 1.0    |
| collage_2.png | 25 | 0  | 0  | 1.0       | 1.0    |
| collage_3.png | 13 | 18 | 12 | 0.42      | 0.52   |

- **TP**: Правильно обнаруженные эллипсы (пересечение с GT > 60%)
- **FP**: Ложные обнаружения (нет соответствия в GT)
- **FN**: Пропущенные эллипсы (не обнаружены)
- **Precision**: Доля правильных обнаружений среди всех срабатываний
- **Recall**: Доля найденных эллипсов от общего количества

## Вывод
- Алгоритм детектирует все границы объектов на изображениях с незначительным и с умеренным шумом
- Основные ошибки возникают при:
  - Высоком уровне шума (FP увеличиваются)
  - Сильном размытии (FN растут)
  - Маленьких размерах эллипсов
