# Отчет по лабораторной работе №4: Генератор коллажей с эллипсами


## Описание программ

### `task04-01` — генерация изображений

- Считывает параметры из `config.json`
- Генерирует `n × n` изображение (размер ячейки — 256×256)
- В каждой ячейке:
  - Фон с заданным цветом (`bg_color`)
  - Один эллипс с заданными диапазонами ширины, высоты, угла
  - Случайное смещение и поворот
  - Применяется размытие (`blur_size`) и шум (`noise_std`)
- Сохраняет изображение и JSON-файл с параметрами (`collage_gt.json`)

### `task04-02` — детектирование эллипсов

- Принимает изображение `collage.png` (одноканальное)
- Разбивает его на сетку 5×5 ячеек размером 256×256 пикселей
- Для каждой ячейки:
  - Применяет гауссово размытие
  - Пороговая бинаризация 
  - Поиск контуров
  - Отбрасывает близкие дубликаты (по центру в пределах 20 пикселей)
- Сохраняет координаты и параметры эллипсов в JSON (`detected_collage_X.json`)

---

### `task04-03` — оценка качества

- Принимает два `.lst` файла: список GT-файлов и список файлов с результатами
- Сравнивает каждый детектированный эллипс с эталонным по следующим метрикам:
  - Расстояние центров
  - Разница ширины/высоты
  - Угол поворота
- Вычисляет object precision / recall по объектным метрикам

---
