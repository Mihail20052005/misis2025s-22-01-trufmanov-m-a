# Отчет по лабораторной работе №6: Детектирование объектов с использованием LoG/DoG

## Описание программы

### `task06` — детектор объектов на основе LoG/DoG

* Принимает на вход:
  - Путь к изображению из `lab04`
  - Путь для сохранения JSON с результатами

* Алгоритм работы:
  1. Загрузка изображения в градациях серого
  2. Предварительная обработка:
     - Гауссово размытие (9x9)
     - Нормализация
  3. Построение пирамиды масштабов (3 уровня, масштаб 2x)
  4. Применение Difference of Gaussian (DoG) с 3 масштабами
  5. Поиск локальных максимумов в пространстве масштабов
  6. Фильтрация дубликатов (порог перекрытия 70%)
  7. Сохранение результатов в JSON

* Выходные данные:
  - JSON-файл с параметрами обнаруженных объектов
  - PNG-файл с визуализацией обнаруженных объектов

---

### Формат выходных данных

Пример `LoG_detection_collage.json`:
```json
{
  "detected_objects": [
    {
      "angle": 0,
      "height": 113.103,
      "width": 113.103,
      "x": 708,
      "y": 76
    },
    ...
  ]
}
```

## Отчет: `report.json`

| Файл                | TP | FP | FN | Precision | Recall | blur_size | noise_std |
| ------------------- | -- | -- | -- | --------- | ------ | ---------- | ---------- |
| collage_1.png | 25 | 0  | 0  | 1.0       | 1.0    | 25          | 15        |
| collage_2.png | 24 | 0  | 1  | 1.0       | 0.96    | 125          | 128        |
| collage_3.png | 16 | 0  | 9  | 0.875     | 0.64   | 333          | 488       |

- **TP**: True Positives - Объекты, которые были и правильно найдены.
- **FP**: False Positives - Объекты, которые не было, но алгоритм нашёл лишние.
- **FN**: False Negatives - Объекты, которые были, но не были найдены.
- **Precision (точность)**: доля правильно найденных объектов среди всех найденных.
- **Recall (полнота)**: доля правильно найденных объектов среди всех, что были на самом деле.
- **blur_size**: размер размытия.
- **noise_std**: стандартное отклонение шума.
