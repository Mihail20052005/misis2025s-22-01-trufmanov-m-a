# Отчет по лабораторной работе №5
---

### Часть 1

Коллаж картинок, созданный сочетанием трех цветов (0,127,255), где каждая из 6 картинок - комбинация пары цветов.
Картинка - это квадрат 127 на 127 пикселей, по центру круг радиусом 40 пикеселей.
Картинки не должны сливаться.


### Часть 2

Применение разных фильтров к этому коллажу.
- 1 фильтр: [[1, 0, -1], [2, 0, -2], [1, 0, -1]]
- 2 фильтр: [[-1, -2, -1], [0, 0, 0], [1, 2, 1]]
- 3 фильтр: $\sqrt{filter1^2 + filter2^2}$
- 4 фильтр: объединение всех трёх фильтров в RGB формат

Результат - объединение всех четырёх фильтров в итоговую визуализацию
